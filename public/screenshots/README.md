# 真实产品 walkthrough

`walkthrough.webp` 是一张约 156 KB 的组合图，展示偏好 → 候选与抽取 → 推荐结果 → 本机记录。它由 `source/` 中的 4 张当前界面截图自动裁切、缩放、组合；没有重绘界面或编造推荐结果。`walkthrough-mobile.webp` 是同 4 步单列版，约 147 KB，供手机作品集封面使用。

## 来源与边界

- 界面实现版本：`3546896da4d8874737a580afdd7041d87fc813b4`，2026-10-07 本地启动并操作；本轮仅修改展示文档和素材。
- 使用独立、空白的演示浏览器，不读取已有用户历史或账号。
- 实际选择：预算 20–30 元、微辣、正常吃、1 人、30 分钟；候选与照烧鸡腿饭结果由应用原有逻辑生成。
- 通过真实“收藏菜品”和“就吃这个”控件生成收藏与历史。
- “演示店铺（虚构）”和约 28 元是明确的虚构手动输入，展示保存功能，不代表真实店铺或实时价格。
- 菜品图片来自仓库既有代表性 AI 食物素材，不是实际餐厅照片。
- 组合图第 4 步明确标注“页面摘录”，是同一页面的真实局部截图。
- [`provenance.json`](provenance.json) 记录截图尺寸、哈希、实现版本与演示输入。

## 复现

1. 按根 README 启动当前版本；以空白浏览器完成 5 项偏好。
2. 生成候选、进入抽取、确认结果、收藏，然后打开“我的口味”。如需示例店铺，明确使用虚构名称。
3. 在 1200 × 900 视口下截取 `main` 区域，保存为与 `source/` 一致的文件名。若重新抽到其他菜品，更新来源记录；不固定或替换抽取结果。
4. 使用 Pillow 与包含中英文的字体运行 `python scripts/build_walkthrough.py`。可通过 `--font` 指定字体；脚本只组合已有截图。

不需要 GIF；静态图即可说明完整流程，并避免自动播放和较大下载。
